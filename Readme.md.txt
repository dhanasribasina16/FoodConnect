#  FOODCONNECT - To Supply Leftover Food to Poor  

**FoodConnect** is a Salesforce-based application designed to bridge the gap between food donors and recipients. Built entirely on the Salesforce platform, it leverages custom objects, automation tools, and Lightning components to reduce food waste and streamline the logistics of food distribution through a centralized, scalable system.  

---

##  Project Overview  
FoodConnect is a Salesforce-powered platform designed to **reduce food wastage** while addressing **hunger in underserved communities**.  
The system connects surplus food providers (restaurants, supermarkets, event organizers) with NGOs, shelters, and individuals in need.  

**Key goals:**  
- Minimize food waste.  
- Provide a structured and scalable distribution system.  
- Empower volunteers and organizations with actionable data.  
- Automate processes for efficiency and accuracy.

##  Project Structure  

### 1. Salesforce Developer Account Creation  
- Instructions to set up your Salesforce Developer Account to begin building the platform.  

### 2. Objects  
Custom objects created to manage core entities:  
- **Drop-Off Point**  
- **Execution Details**  
- **Task**  
- **Venue**  
- **Volunteer**  

### 3. Tabs  
- Steps to create **custom tabs** for easy navigation within the Salesforce app.  

### 4. Lightning App  
- A **user-friendly Lightning App** to allow seamless interaction between donors, volunteers, and recipients.  

### 5. Fields  
- Custom fields and relationships defined for each object to ensure **comprehensive data management**.  

### 6. Flows  
- Automated workflows using **Salesforce Flows** for process efficiency.  

### 7. Trigger  
- `DropOffTrigger.tgr`: A custom trigger to handle **event-driven logic** and automate critical actions.  

### 8. Profiles & Permissions  
- Define **user access levels** and permissions to maintain security and proper data governance.  

### 9. User Creation  
- Guide for creating users and assigning roles effectively.  

### 10. Public Groups & Report Types  
- Organize users into **public groups**.  
- Create **dynamic report types** for analytics.  

### 11. Reports  
Pre-built reports include:  
- **Venue with Drop-Off and Volunteer**  
- **Volunteers with Execution Details and Tasks**  

### 12. Dashboards & Home Page  
- Create **visually appealing dashboards**.  
- Set up a **dynamic home page** for quick access to insights.

##  Features  
- Salesforce-native application (no external dependencies).  
- Centralized food donation and distribution system.  
- Real-time tracking of food drop-offs, volunteers, and venues.  
- Automated notifications and flows.  
- Data-driven insights via reports and dashboards.
